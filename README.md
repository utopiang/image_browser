# 图片浏览器 (Image Browser)

一款轻量级图片浏览工具，支持图片预览、缩放拖动、分类标记、批量复制/移动，辅助完成图像数据集筛选、分类。

## 功能特性

### 核心功能
| 功能 | 说明 |
|------|------|
| 图片预览 | 支持 jpg、jpeg、png、bmp 格式，可打开目录浏览 |
| 缩放拖动 | 鼠标滚轮缩放（以鼠标为中心），左键拖拽平移 |
| 上下张切换 | 工具栏按钮或键盘方向键/空格切换 |
| 分类标记 | 可添加多个分类（如"晴天"、"阴天"），点击标记，生成同名 txt 文件 |
| 复制/移动 | 将当前图片复制/移动到指定目标目录 |
| 批量操作 | 选择含路径列表的 txt 文件，批量复制/移动到目标目录 |
| 撤销功能 | 支持撤销复制、移动、标记操作；批量操作一次撤销全部 |
| 进度保存 | 关闭后重新打开自动恢复到上次浏览位置 |
| 递归子目录 | 可选是否读取子目录中的图片 |
| 快速定位 | 状态栏滑块拖动定位，输入数字跳转到指定位置 |
| 批量后定位 | 批量操作完成后自动定位到本次最后一个文件的下一张 |

### 快捷键
| 快捷键 | 功能 |
|------|------|
| → / 空格 / D | 下一张 |
| ← / A | 上一张 |
| F | 适应窗口 |
| Ctrl+Z | 撤销 |
| 输入数字+回车 | 跳转到指定图片 |

## 安装与运行

### 方式一：直接运行 exe（推荐）

1. 下载 `dist/ImageBrowser.exe`
2. 双击运行，无需安装

### 方式二：从源码运行

```bash
# 1. 克隆项目
git clone <repo-url>
cd image_browser

# 2. 创建 conda 环境
conda create -n py310 python=3.10
conda activate py310

# 3. 安装依赖
pip install PyQt6>=6.6 Pillow>=10.0

# 4. 运行
python main.py
```

### 方式三：打包

```bash
python build.py
# 输出: dist/ImageBrowser.exe
```

## 使用说明

### 1. 打开目录
点击工具栏"打开目录"按钮，选择包含图片的文件夹。

### 2. 浏览图片
- 滚动鼠标滚轮缩放图片
- 按住左键拖拽平移
- 点击"◀ 上一张"/"下一张 ▶"或使用方向键切换

### 3. 标记分类
- 点击侧边栏"标记分类"下的分类按钮标记当前图片
- 标记后在图片所在目录生成对应的 txt 文件（如"晴天.txt"），每行一个被标记图片的绝对路径
- 已标记的按钮显示红色高亮

### 4. 添加/删除分类
- 点击"+ 添加分类"输入新分类名称
- 右键点击分类按钮，选择"删除"移除分类

### 5. 复制/移动图片
- 在"目标目录"列表中添加目标文件夹
- 选中一个目标目录，点击"复制到选中目录"或"移动到选中目录"

### 6. 快速定位
拖动状态栏滑块可快速跳转到任意图片位置；也可在进度输入框输入数字（如 5）后回车跳转，越界输入自动忽略。

### 7. 批量操作
- 点击侧边栏"批量操作..."
- 选择包含文件路径列表的 txt 文件（每行一个绝对路径）
- 选择目标目录，选择操作类型（复制/移动）
- 点击"开始执行"，完成后自动定位到本次最后一个文件的下一张

### 8. 撤销
- 点击"撤销"按钮或按 Ctrl+Z
- 批量操作后点击一次撤销全部
- 单张操作撤销最近一条

## 配置说明

配置文件位于 `~/.image_browser/config.json`，包含：
- 目标目录列表
- 标记分类列表
- 上次浏览目录和进度
- 窗口尺寸

标记数据存储在图片所在目录的 txt 文件中（如"漏检.txt"），每行一个绝对路径，可被外部工具读取。

## 常见问题

**Q: 标记文件在哪里？**
A: 在图片所在目录下，文件名为分类名称（如"晴天.txt"）。

**Q: 批量操作的文件列表格式？**
A: 每行一个图片的绝对路径，UTF-8 编码的 txt 文件。

**Q: 撤销能恢复被移动的文件吗？**
A: 可以，撤销会将文件移回原目录。

**Q: 如何分享标记结果？**
A: 直接分享图片目录下的 txt 文件即可，每行一个绝对路径。
