# 图片筛选工具 (Image Browser)

一款基于 Tkinter 的轻量级图片浏览与数据集筛选工具，支持图片预览、缩放拖动、YOLO 标签可视化、分类标记、批量复制/移动、视频抽帧（decord 引擎）、相似图片去重（CPU pHash + 颜色直方图）等功能。

> 当前版本：**v1.0.23**（CPU-only）
> 自 v1.0.20 起已完全移除 GPU/CUDA/torch 依赖，去重改为纯 CPU 的 pHash + 颜色直方图，视频抽帧统一使用 decord 引擎，并精简了打包体积。

## 功能特性

### 核心功能

#### 1. 数据浏览
| 功能 | 说明 |
|------|------|
| 图片预览 | 支持 jpg、jpeg、png、bmp、webp 等格式，可打开目录浏览 |
| 缩放拖动 | 鼠标滚轮缩放（以鼠标为中心），左键拖拽平移 |
| 上下张切换 | 工具栏按钮或键盘方向键切换 |
| 递归子目录 | 可选是否读取子目录中的图片 |
| 快速定位 | 状态栏滑块拖动定位，输入数字跳转到指定位置 |
| 进度保存 | 关闭后重新打开自动恢复到上次浏览位置 |

#### 2. 标签显示与编辑
| 功能 | 说明 |
|------|------|
| YOLO 标签可视化 | 支持 HBB / OBB / 多边形标签绘制与编辑 |
| 类别过滤 | 可勾选显示/隐藏特定类别的标签，列表超 6 项自动出现滚动条 |
| 标签同步操作 | 图片复制/移动时自动同步同名标签文件 |
| 标签格式支持 | YOLO 格式（.txt），每行包含 class_id 和边界框/关键点坐标 |
| 匹配图片列表 | 标签目录下匹配到标签的图片以列表形式展示（含滚动条、当前行高亮） |
| classes 文件历史 | 上传过的 classes 文件路径会被记住，下次可从下拉框快速选择 |
| 路径友好显示 | 标签目录、classes 文件、COCO JSON、转移目录等长路径自动缩短，鼠标悬停显示完整路径 |

#### 3. 标记转移
| 功能 | 说明 |
|------|------|
| 分类标记 | 可添加多个分类（如「合格」「不合格」「漏检」「误检」），点击标记 |
| 横向按钮布局 | 标记分类按钮左右排布，节省纵向空间 |
| 批量标记 | 支持批量操作，对选中图片进行标记 |
| 标记文件 | 标记后在图片所在目录生成对应的 txt 文件 |
| 一键转移 | 「批量转移」按钮自动选择目标目录并执行转移；「更改目录」可单独指定 |
| 标签同步 | 图片复制/移动时自动同步处理标签文件 |

#### 4. 视频抽帧
| 功能 | 说明 |
|------|------|
| 抽帧引擎 | 统一使用 **decord** 引擎，批量解码（按 chunk_size），批量失败自动回退逐帧解码 |
| 视频选择 | 支持选择视频文件夹，批量处理 |
| 抽帧间隔 | 可设置按时间间隔（秒）或按帧数间隔抽帧 |
| 灰图过滤 | 自动检测并跳过灰帧（gray_thresh 可调） |
| 相似帧过滤 | 自动过滤相邻相似帧（sim_thresh 可调） |
| 输出组织 | 支持平铺（所有图片放输出根目录，以视频名为前缀）或按视频子文件夹组织（flat_save 参数） |
| 输出格式 | 支持 PNG 输出，可配置压缩级别 |
| 进度显示 | 实时显示处理进度和已处理视频数 |

#### 5. 相似去重
| 功能 | 说明 |
|------|------|
| 算法模式 | 纯 CPU 模式：pHash + 颜色直方图（无需 GPU） |
| 参数调节 | pHash 距离阈值 + 颜色相似度阈值 |
| 智能聚类 | 自动将相似图片分组，支持查看和管理 |
| 缩略图缓存 | 加速大量图片的相似度结果显示 |

## 工作台与交互设计

参考 [X-AnyLabeling 的界面与交互习惯](https://github.com/CVHub520/X-AnyLabeling/blob/main/docs/en/user_guide.md)，使用独立实现的图标和 Tkinter 控件。

- 顶部仅保留 **图片工作台 / 视频抽帧 / 相似去重** 三个入口。
- 左侧竖向图标工具栏：打开、保存、撤销、浏览、选择、HBB、OBB、多边形、适应窗口、显示标签、导入、导出。悬停可查看名称与快捷键，当前工具高亮。
- 图片工作台采用 **图片库 → 预览 → 属性与操作** 布局。打开目录即预览；右侧概览、标签检查、分类整理共用同一张图片。
- 图片列表支持文件名 / 相对路径搜索，200 张一页，避免大目录一次创建过多控件。搜索状态下上一张、下一张按搜索结果切换。
- 低频来源与格式、分类管理按需展开；日志默认收起。欢迎页可主动继续上次浏览。

## 标注能力与格式

| 形状 | 新建与编辑 | 原生格式 |
|---|---|---|
| 水平框 HBB | 拖动新建、移动、8 个控制点缩放 | YOLO detect / LabelMe rectangle / COCO bbox |
| 旋转框 OBB | 拖动新建、角点缩放、蓝色手柄旋转 | YOLO OBB / X-AnyLabeling rotation |
| 多边形分割 | 逐点绘制、闭合、顶点移动；Shift 点边加点、Ctrl 点顶点删点 | YOLO segment / LabelMe polygon / COCO segmentation |

右侧对象列表可选中当前标注，双击修改类别。绘制后自动回到选择工具；默认浏览模式不会因拖动图片而改动标签。保存失败时保持当前图片，关闭自动保存后切图提供保存、放弃、取消。

### 导入与自动转换

1. 打开图片文件夹，自动发现同目录或同级 `labels` 中匹配的 YOLO / LabelMe 标注。
2. 也可从「标签」菜单或导入图标选择标注目录、LabelMe JSON、COCO JSON；预测标签使用独立目录，保持只读。
3. 点击导出图标或「导出 / 转换标注」，选择当前 / 全部图片，再选择 LabelMe、COCO、YOLO HBB、YOLO OBB 或 YOLO 分割。
4. 选择输出位置。工具创建新子目录、保留图片相对层级、转换像素与归一化坐标和类别 ID，并输出 `conversion_report.json`。
5. 完成后可直接「加载转换结果」。此操作转换标注，不复制图片。

格式注意事项：

- YOLO 自动识别采用标准 `cx cy w h`。对于 `xyxy` 和四点 polygon，请在「来源与格式设置」中关闭自动识别并指定。四点 polygon 与 OBB 的文本布局相同，无法可靠猜测。
- 本工具导出的 YOLO 含任务描述；编辑写回时也保存形状类型辅助信息。供训练使用时，请按单一目标任务导出。
- COCO 使用稀疏 category_id 时按类别名称映射；导出时生成连续 ID，映射列于报告。同一实例的 bbox 与 segmentation 不重复显示，多部件分割保留分组。
- COCO 标准没有独立 OBB 类型，采用四角 segmentation 并附加 `shape_type=rotation`；其他软件可能将其按多边形读取。
- LabelMe 使用像素坐标；自定义归一化 JSON 需声明 `coordinateSystem: "normalized"`。保存保留 flags、group_id、description 等字段。
- 转外接框会减少边界或角度信息；标准 YOLO 训练标签不携带附加 JSON 属性。转换报告会列出这些差异。
- 支持 COCO 压缩 / 未压缩 RLE。未编辑的 mask 原样保留；含孔洞的 mask 可改类别或整体删除，轮廓暂不编辑，也不静默转为会丢失孔洞的 polygon。
- 当前统一编辑与转换范围是 HBB、OBB、多边形。LabelMe 中其他形状可原样保留；关键点等任务的跨格式转换暂不支持。

## 安装与运行

### 环境要求
- Python 3.8+
- Windows 10/11
- 无需 GPU，纯 CPU 运行

### 依赖安装

```bash
# 创建 conda 环境（推荐）
conda create -n image_browser python=3.10
conda activate image_browser

# 安装核心依赖（见 requirements.txt）
pip install -r requirements.txt
```

`requirements.txt` 内容：

```
Pillow>=10.0
opencv-python-headless>=4.8
appdirs>=1.4.4
decord>=0.6
```

> numpy 作为 opencv / decord 的依赖会被自动安装。

### 运行程序

```bash
# 进入项目目录
cd image_browser

# 直接运行
python main.py
```

## 打包为 exe

### 环境要求
- Python 3.8+
- Windows 10/11
- PyInstaller: `pip install pyinstaller`

### 打包（CPU-only）

```bash
# 安装 PyInstaller
pip install pyinstaller

# 进入项目目录
cd image_browser

# 运行打包脚本（默认 onefile + 窗口模式）
python build.py

# 可选参数
python build.py --console      # 保留控制台窗口（调试用）
python build.py --onedir       # 打包为文件夹而非单文件
```

输出文件：`dist/ImageBrowser.exe`

`build.py` 已针对体积做精简，排除未使用的标准库（asyncio、email、http、urllib、xml 等）、第三方库（matplotlib、scipy、pandas、PyQt5/6 等）、tkinter 子模块以及大部分 PIL 图像格式插件（仅保留 jpg/png/bmp/webp/tif）。

### 注意事项

#### 文件体积
- **CPU 版本**：体积较小，依赖少，适合所有用户

#### 常见问题

**Q: 打包失败怎么办？**
A:
- 检查 PyInstaller 是否正确安装：`pip show pyinstaller`
- 清理缓存后重试：`rmdir /s /q build dist 2>nul & python build.py`
- 查看详细错误信息

## 使用说明

### 1. 图片浏览

打开图片目录后直接浏览；左侧搜索定位，中间滚轮缩放、拖动平移。点击左右箭头或 A / D 切图，输入序号回车跳转，F 适应窗口。

### 2. 标注检查

切换右侧「标签检查」。竖向工具栏提供浏览、选择、HBB、OBB 和多边形工具；对象列表与画布选择联动，双击对象修改类别。Ctrl+S 保存，Ctrl+Z 撤销，Delete 删除选中标注。标注来源和手动格式选项收纳在「来源与格式设置」。

### 3. 分类整理

切换右侧「分类整理」，点击分类按钮标记，再点同一分类取消。需要自动跳图时勾选「标记后下一张」。选择待转移分类和目标目录后点击转移，确认数量与路径。分类新增、删除和文本编辑统一放入「管理分类」。文件转移与标签编辑撤销独立，**Ctrl+Z 不恢复已经转移的文件**。

### 4. 视频抽帧
1. 切换到「视频抽帧」面板
2. 点击「视频文件夹」选择包含视频的目录
3. 点击「输出文件夹」选择抽帧图片的输出目录
4. 设置抽帧间隔（秒或帧数）
5. 可选：开启/关闭平铺保存（flat_save）、灰图过滤阈值、相似帧过滤阈值
6. 点击「开始抽帧」启动处理（使用 decord 引擎，支持多视频任务）

### 5. 相似去重
1. 切换到「相似去重」面板
2. 点击「图片文件夹」选择需要检测的目录
3. 设置相似度参数：
   - **pHash 距离**（0-64）：越小越严格
   - **颜色相似度**（0-1）：越大越宽松
4. 点击「扫描」开始检测（纯 CPU）
5. 扫描完成后点击「查看」浏览相似图片组
6. 选择需要删除的重复图片，点击「转移」进行清理

## 算法说明

### 相似去重（CPU pHash + 颜色直方图）
- **pHash**：感知哈希算法，通过比较图像的哈希值判断相似度
  - pHash 距离越小，表示图片越相似
  - 距离 ≤ 2：直接判定为相似
  - 距离在阈值内：结合颜色直方图综合判断
- **颜色相似度**：通过比较颜色直方图判断颜色相似程度
  - 值越大，表示颜色越相似（找出更多相似图片）

## 配置说明

配置文件位于 `~/.image_browser/tk_config.json`，包含：
- 上次浏览目录和进度
- 分类标记列表
- 相似去重任务配置
- classes 文件历史记录
- 性能模式设置

标记数据存储在图片所在目录的 txt 文件中（如「合格.txt」），每行一个绝对路径。

## 常见问题

**Q: 标记文件在哪里？**
A: 在图片所在目录下，文件名为分类名称（如「合格.txt」）。

**Q: 相似去重的参数如何调节？**
A: pHash 距离越小越严格，颜色相似度越大越宽松；颜色相似度越大，找出的相似图片越多。

**Q: 批量操作时标签会同步吗？**
A: 会。图片复制/移动时会自动查找并同步处理同名 `.txt` 标签文件。

**Q: 撤销能恢复被移动的文件吗？**
A: 目前 Ctrl+Z 只撤销标注编辑，不能恢复已转移文件。

**Q: 需要安装 GPU 驱动或 CUDA 吗？**
A: 不需要。v1.0.20 已移除全部 GPU/CUDA/torch 依赖，相似去重与视频抽帧均纯 CPU 运行。
